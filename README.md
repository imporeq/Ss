# 喰種 KAGUNE-KAI

Фанатский сайт-архив по вселенной «Токийского гуля». Пять страниц, никаких
фреймворков и сборки: HTML + CSS + чистый JS. Вся графика нарисована в SVG
и на canvas прямо в коде — ни одной картинки, поэтому репозиторий открывается
как есть, хоть с флешки.

## Страницы

| Файл | Что внутри |
|---|---|
| `manga.html` | «Отрывки» — четыре сцены, пересказанные нарисованными кадрами: облака реплик, звуки катаканой, подписи |
| `index.html` | Ворота с открывающимся какуганом, RC-клетки на canvas, биология гуля, счётчик «1000 − 7», цитаты, хронология арок |
| `characters.html` | Картотека CCG: 24 досье, фильтры, поиск, модалка с вымаранными строками (кликаются) и полосами характеристик |
| `kagune.html` | Четыре типа кагуне, круг преимуществ и опросник «какое кагуне выросло бы у тебя» |
| `wards.html` | Интерактивная карта 23 районов + 24-й, справка по каждому и меню кофейни «Антейку» |
| `atelier.html` | Ателье масок HySy: конструктор маски (форма, прорези, узор, деталь, материал) со скачиванием готового SVG |

## Что стоит найти

* **Какуган на входе** — глаз открывается один раз за сессию, дальше не мешает.
* **1000 − 7** на главной. Двадцать нажатий — и сайт переходит в «пробуждение»:
  белая инверсия темы, которая запоминается в `localStorage`. Вернуть тьму —
  круглая кнопка-глаз слева внизу на любой странице или кнопка в подвале;
  обе переключают тему в обе стороны.
* **Сороконожка.** Открой дело № 001 (Кен Канеки) — по экрану пройдёт сороконожка
  поверх всего, что открыто, и экран дрогнет.
* **Вымаранные строки** в досье: клик по чёрной плашке проявляет текст.
* **Портреты** генерируются из `id` персонажа — форма глаза, наклон, вены
  и радужка каждый раз считаются заново, но всегда одинаково для одного дела.
* **Скачивание маски** в ателье отдаёт самостоятельный SVG-файл.
* **Набери «гуль» или «ghoul»** на любой странице — прибежит сороконожка.
  Наберёшь «кофе» — архив ответит.
* **Код Конами** (↑↑↓↓←→←→ B A) — пробуждение силой плюс сороконожка.
* **Пять кликов по эмблеме** в шапке — какуган на логотипе, запоминается.
* **24-й район** на карте: клик по пунктирной полосе гасит свет, дальше
  ходишь с фонариком. Выключается кликом или через 12 секунд.

## Эффекты прокрутки

* Полоса прогресса чтения сверху.
* Манга-линии скорости при быстрой прокрутке (красные вниз, светлые вверх).
* Шторка-переход у каждой крупной секции при появлении в кадре.
* Моргание какугана при переходе между страницами.

## Структура

```
index.html  manga.html  characters.html  kagune.html  wards.html  atelier.html
assets/
  css/main.css    — токены, шапка, курсор, ворота, типографика, темы
  css/pages.css   — секции конкретных страниц
  js/data.js      — весь контент архива (персоналии, районы, кагуне, тест, меню)
  js/core.js      — общее: ворота, курсор, меню, скролл-эффекты, генератор портретов
  js/centipede.js — сороконожка на canvas поверх страницы
  js/fx.js        — прогресс, линии скорости, шторки, моргание, тема, пасхалки
                    (грузится последним: ловит секции, созданные другими скриптами)
  js/home.js  js/characters.js  js/kagune.js  js/wards.js  js/atelier.js  js/manga.js
```

## Запуск

Открыть `index.html` в браузере. Для локального сервера:

```bash
python3 -m http.server 8000
```

Шрифты подтягиваются с Google Fonts; без сети сайт работает на системных
запасных начертаниях.

## Доступность и мелочи

* Всё интерактивное доступно с клавиатуры (карточки досье, клетки карты,
  вымаранные строки, узлы круга кагуне).
* `prefers-reduced-motion` отключает ворота, анимацию RC-клеток и печатную
  машинку в цитатах.
* Ни одной горизонтальной прокрутки от 390px и выше.
