# 喰種 KAGUNE-KAI

Фанатский сайт-архив по вселенной «Токийского гуля». Десять страниц, никаких
фреймворков и сборки: HTML + CSS + чистый JS. Вся графика нарисована в SVG
и на canvas прямо в коде — ни одной картинки, поэтому репозиторий открывается
как есть, хоть с флешки.

## Страницы

| Файл | Что внутри |
|---|---|
| `index.html` | Ворота с открывающимся какуганом, RC-клетки на canvas, биология гуля, счётчик «1000 − 7», цитаты, хронология арок, врезка про игру |
| `manga.html` | «Отрывки» — шесть сцен, пересказанных нарисованными кадрами: облака реплик, звуки катаканой, подписи |
| `characters.html` | Картотека CCG: 24 досье, фильтры, поиск, модалка с вымаранными строками, радаром характеристик и выгрузкой карточки; листание стрелками |
| `kagune.html` | Четыре типа кагуне, круг преимуществ и опросник «какое кагуне выросло бы у тебя» |
| `quinque.html` | Оружейная CCG: 12 квинке с нарисованными силуэтами, доспех Арата, программа Quinx и разбор кагуджи |
| `factions.html` | Организации: CCG, Древо Аогири, «Антейку», Клоуны, клан Вашу, отряд Quinx и «V» — у каждой своя эмблема |
| `terms.html` | Словарь архива: 25 статей с фильтром по разделам и живым поиском с подсветкой |

## Управление

* **`/` или `Ctrl+K`** — поиск по всему архиву: дела, районы, кагуне, квинке,
  отрывки, разделы. Стрелки выбирают, Enter открывает.
* **Глаз слева внизу** — переключает тьму и «пробуждение» в обе стороны.
* **`←` `→`** внутри досье — листают картотеку, не закрывая карточку.
* **«Скачать досье карточкой»** в любом деле — отдаёт самостоятельный SVG
  с портретом, характеристиками и цитатой; открывается и без сайта.
* **`Esc`** — закрывает всё открытое.

## Что стоит найти

* **Какуган на входе** — глаз открывается один раз за сессию.
* **1000 − 7** на главной. Двадцать нажатий — и сайт переходит в «пробуждение»:
  белая инверсия темы, которая запоминается в `localStorage`.
* **Сороконожка.** Открой дело № 001 (Кен Канеки) — по экрану пройдёт сороконожка
  поверх всего, что открыто, и экран дрогнет.
* **Вымаранные строки** в досье: клик по чёрной плашке проявляет текст.
* **Портреты** генерируются из `id` персонажа — форма глаза, наклон, вены
  и радужка считаются заново, но всегда одинаково для одного дела.
* **Набери «гуль» или «ghoul»** на любой странице — прибежит сороконожка.
  Наберёшь «кофе» — архив ответит.
* **Код Конами** (↑↑↓↓←→←→ B A) — пробуждение силой плюс сороконожка.
* **Пять кликов по эмблеме** в шапке — какуган на логотипе, запоминается.
* **24-й район** на карте: клик по пунктирной полосе гасит свет, дальше
  ходишь с фонариком.

## Эффекты прокрутки

* Полоса прогресса чтения сверху.
* Манга-линии скорости при быстрой прокрутке (красные вниз, светлые вверх).
* Шторка-переход у каждой крупной секции при появлении в кадре.
* Моргание какугана при переходе между страницами.
* Оглавление страницы слева на широких экранах.

## Структура

```
index.html  manga.html  characters.html  kagune.html  quinque.html
factions.html  terms.html  wards.html  atelier.html  game.html
assets/
  css/main.css    — токены, шапка, курсор, ворота, типографика, темы, поиск
  css/pages.css   — секции конкретных страниц
  js/data.js      — весь контент архива: персоналии, районы, кагуне, квинке,
                    кагуджа, организации, словарь, отрывки, тест, меню, ночи игры
  js/core.js      — общее: меню и подвал из одного источника, ворота, курсор,
                    скролл-эффекты, генератор портретов
  js/search.js    — поиск по архиву (/ и Ctrl+K)
  js/centipede.js — сороконожка на canvas поверх страницы
  js/fx.js        — прогресс, линии скорости, шторки, моргание, тема, оглавление,
                    пасхалки (грузится последним: ловит секции от других скриптов)
  js/home.js  js/manga.js  js/characters.js  js/kagune.js  js/quinque.js
  js/factions.js  js/terms.js  js/wards.js  js/atelier.js  js/game.js
  img/            — иконки приложения и превью для ссылок (сгенерированы кодом)
manifest.json     — для «добавить на главный экран»
```

Шапка и подвал собираются в `core.js` из одного списка `SITE` — добавить
страницу значит дописать одну строку, а не править десять файлов. Пункты,
которые не помещаются в верхний ряд, живут в группе «Архив»: на широком
экране это выпадающий список, на телефоне — раскрывающийся подраздел.

## На телефоне

В шапке страницы объявлен `manifest.json`, поэтому в Chrome на Android
работает «Добавить на главный экран»: сайт открывается без адресной строки
и со своей иконкой (`assets/img/icon-*.png`, есть маскируемый вариант).
Ссылки при отправке в мессенджеры разворачиваются в карточку —
за неё отвечают Open Graph-теги и `assets/img/og.png`.

Абсолютные адреса в тегах указывают на `https://imporeq.github.io/Ss/`.
Если сайт будет жить по другому адресу, поменяй базу в `og:url` и `og:image`.

## Запуск

Открыть `index.html` в браузере. Для локального сервера:

```bash
python3 -m http.server 8000
```

Шрифты подтягиваются с Google Fonts; без сети сайт работает на системных
запасных начертаниях.

## Доступность и мелочи

* Всё интерактивное доступно с клавиатуры, есть ссылка «к содержимому»
  и видимая рамка фокуса.
* `prefers-reduced-motion` отключает ворота, RC-клетки, линии скорости,
  шторки, моргание и сороконожку.
* Ни одной горизонтальной прокрутки от 390px и выше.
